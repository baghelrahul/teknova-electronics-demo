# TEKNOVA / NEXORA — Ultra-Premium Electronics Storefront (Live Preview)

Live interactive preview of the **TEKNOVA / NEXORA** flagship electronics theme, built with high-output editorial aesthetics, Tailwind CSS, Google Material Symbols, and responsive layout architectures.

## ✨ Features
- **Editorial Apple/Nothing Aesthetic**: Dynamic contrast typography, dark/light ambient tokens, and studio hardware layout.
- **Top Announcement Ticker**: Rotating promo notifications with multi-currency and regional support.
- **Sticky Navigation**: Live search, category anchor links, reactive wishlist badge, and cart counter.
- **Product Showcase**: Floating spec pills, customer favorites grid, urgency stock badges, and flash deals with countdown timers.
- **Interactive UI**: Reactive heart wishlist toggles and Add-to-Cart toast notifications.

## 🚀 Deployment
This repository is optimized for zero-configuration, instant static deployment on [Netlify](https://www.netlify.com).
- **Publish directory**: `.`
- **Entry file**: `index.html`
